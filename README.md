Employee Data Analysis

📌 Project Overview

This project focuses on analyzing employee data from ABC Company. The dataset contains information about 458 employees across different teams and positions.

The main objective of this project is to preprocess the data, perform exploratory data analysis, identify important patterns, and present the findings using suitable visualizations.

📊 Dataset

The dataset contains 458 rows and 9 columns with information about employees.

The analysis focuses on attributes such as:

- Team
- Position
- Age
- Salary
- Height
- Other employee-related information

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

🧹 Data Preprocessing

The following preprocessing was performed:

- Checked the dataset for missing values.
- Examined the dataset for consistency.
- Corrected the "Height" column by replacing the existing values with randomly generated values between 150 and 180.

🔍 Analysis Performed

1. Team Distribution

Analyzed the number of employees belonging to each team and calculated the percentage of employees in each team.

2. Position-wise Employee Distribution

Analyzed how employees are distributed across different positions in the company.

3. Predominant Age Group

Grouped employees into different age categories and identified the age group with the highest number of employees.

4. Salary Expenditure

Identified:

- The team with the highest total salary expenditure.
- The position with the highest total salary expenditure.

5. Age and Salary Relationship

Investigated the relationship between employee age and salary using correlation analysis and a heatmap.

📈 Visualizations

The following visualizations were created:

- Team-wise employee distribution
- Team-wise percentage distribution
- Position-wise employee distribution
- Age-group distribution
- Team-wise salary expenditure
- Position-wise salary expenditure
- Age vs Salary as correlation heatmap

💡 Key Insights

The analysis helped identify important patterns in the employee dataset, including:

- The team with the largest number of employees.
- The most common position among employees.
- The predominant age group.
- The team with the highest salary expenditure.
- The position with the highest salary expenditure.
- The relationship between age and salary.

🚀 Conclusion

This project demonstrates the use of Python and data analysis libraries to preprocess, analyze, visualize, and communicate insights from an employee dataset.
The project also helped in understanding how data can be transformed into meaningful information to support business analysis and decision-making.
